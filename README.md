### About me

I'm a Computer Systems Engineering student at **Instituto Tecnológico de Zacatepec**, Mexico. I build computer-vision systems focused on accessibility, particularly Mexican Sign Language recognition.

My long-term goal is to become a research engineer capable of turning ideas from papers into reliable systems. I'm currently strengthening my foundations in linear algebra, probability, optimization and machine learning while training for **ICPC México**.

Currently: studying olympiad mathematics — combinatorics, number theory, geometry and algebra — alongside the mathematical foundations of machine learning and data science, including linear algebra, probability, statistics, calculus and optimization.

### Selected projects

* **[LSM Learning App](https://github.com/cristoballongares/talkhand_android)** — Android application that teaches Mexican Sign Language through real-time hand-sign recognition and interactive quizzes. Built with Java, Python, MediaPipe, OpenCV and classical ML classifiers. **[Documentation](https://github.com/cristoballongares/talkhand_android/blob/master/docs/talkhand_report.pdf)**

* **[LSM Vowel Interpreter](https://github.com/cristoballongares/TalkHand)** — Desktop application that recognizes LSM vowels from webcam input using hand-landmark features. Built with C#, Python and WinForms. **[Documentation](https://github.com/cristoballongares/TalkHand/blob/master/docs/talkhand_report.pdf)**

* **[ICPC Team Training Platform](https://github.com/cristoballongares/DBCWorkspace/tree/main)** — TypeScript web application for organizing and tracking my team's competitive-programming training.

* **[cp-notebook](https://github.com/cristoballongares/cp-notebook)** — Competitive-programming notebook containing C++ algorithms, templates, complexity analysis and notes, typeset in LaTeX.
